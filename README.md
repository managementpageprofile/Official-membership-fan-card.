# JEFF TEAM MEMBERSHIP FAN CARD

Upload all files to your GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from a branch → main → root.

After GitHub gives you the public Pages address, replace `YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY` in `robots.txt` and `sitemap.xml` with your real address.

For Google discovery, add the public site to Google Search Console, submit `sitemap.xml`, and use URL Inspection to request indexing. Google controls crawling/indexing timing, so first-page or immediate ranking cannot be guaranteed.

Forms use `mailto:` and open the visitor's email app with the management email and submitted details prefilled. The visitor must review and send the email. The website cannot force the sender account.
